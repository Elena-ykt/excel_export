README.MD

Данный скрипт сохраняет выделенный диапазон ячеек в открытом файле Excel в файлы форматов .pdf и .png в указываемую вами папку и с указанным именем.

Нужно в открытом файле Excel выделить мышкой нужный диапазон ячеек и запустить скрипт на выполнение.

Для этого нужно (сложный путь):
- Перейти в папку с проектом cd c:/project (на компьютере должен быть установлен Python!!!)
- Установить виртуальное окружение python -m venv venv 
- Активировать виртуальное окружение venv\Scripts\activate  
- Установить библиотеки в активированное виртуальное окружение pip install -r requirements.txt будут установлены указанные в этом файле библиотеки, необходимые для работы скрипта.
- Запустить скрипт python main.py
- Скрипт дважды запросит в какой файл и какую папку сохранять результат - сначала для .pdf, потом для .png
Ваши файлы готовы!


Дополнительно для удобства неподготовленных пользователей (простой путь) возможно запускать готовое приложение по иконке на рабочем столе Windows - main.exe, которое лежит в папке dist - его нужно просто скачать на свой компьютер.
Комментарий для сведения о файле с приложением. Данная команда компилирует python-скрипт в приложение main.exe для того, чтобы не было необходимости устанавливать python на компьютере пользователя.
Для компиляции также нужен файл с иконкой для приложения.
pyinstaller --onefile --noconsole --icon=schedule.ico main.py

Также сохранение в формат .pdf выделенного диапазона ячеек возможно стандартными средствами Excel (через Сохранить как ...), однако в формате .png таким образом сохранить изображение не удастся.


ВАЖНО! Для корректной работы скрипта должен быть открыт для редактирования только один файл Excel.
